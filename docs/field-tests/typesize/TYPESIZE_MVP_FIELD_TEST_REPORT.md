## 1. Executive Summary

This report documents the empirical evaluation of the **27 CFR 16.22 Option A (Scale-Marker) MVP** implementation for the TTB Label Compliance Review Tool.

The MVP provides deterministic Computer Vision (OpenCV/Pillow) calibration using physical scale markers (ISO/IEC 7810 ID-1 standard cards and printable ArUco fiducials) placed adjacent to the Government Warning statement.

### Key Capabilities Verified
1. **Deterministic Scale Calibration:** Detects standard ID-1 cards ($85.60\text{ mm}$ long edge) or ArUco targets to compute exact $\text{px/mm}$ spatial resolution and perspective tilt angle.
2. **Uppercase Glyph Segmentation & Measurement:** Segments capital letters in the Government Warning text region, calculates median capital letter height in millimeters, and computes a 95% confidence interval ($\pm\text{mm}$).
3. **Statutory Threshold Enforcement:** Evaluates measured height against 27 CFR 16.22 volume tiers ($\ge 1.0\text{ mm}$ for $\le 237\text{ mL}$, $\ge 2.0\text{ mm}$ for $237\text{ mL}$ to $3\text{ L}$, $\ge 3.0\text{ mm}$ for $> 3\text{ L}$).
4. **Honest Fail-Open & Uncalibrated Handling:** Uncalibrated photos retain the existing statutory physical gauge advisory with **zero invented mm** and **zero extra Claude round-trips**.
5. **Preservation of Statutory Hard Fails:** Strict casing rules (W03: `GOVERNMENT WARNING:`) and missing warning rules (W02) hard fail even if physical dimensions are compliant.
